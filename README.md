## 🚀 Getting Started

To run any practical locally:

1. Navigate to the practical folder:
   ```bash
   cd p1  # or whichever practical
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the application (refer to each practical's `README.md` for specific instructions):
   ```bash
   npm run dev  # or npm start
   ```
